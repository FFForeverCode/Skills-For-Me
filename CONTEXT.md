# Skills-For-Me Context

This repository is a personal skills collection for coding agents.

## Domain terms

- **Skill**: a command-capability package rooted at a directory that contains `SKILL.md`.
- **Bucket**: a category folder under `skills/` (currently `engineer/`).
- **Linked install**: symlink-based local installation for iterative editing.
- **Copy install**: physical copy installation for isolated execution environments.

## Relationships

- A **Bucket** contains many **Skills**.
- A **Skill** is discoverable when `SKILL.md` exists.
- Installation scripts operate on the set of discoverable skills.
